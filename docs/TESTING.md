# Testing

## Automated

`bash scripts/check.sh` checks:

- JavaScript syntax of every module; the GSettings schema (strict) and Python syntax.
- URI parsing, history deduplication/favourites/retention, tags and native batch-copy formats, calendar day boundaries, ISO calendar weeks and week strips across month and year ends, notification grouping, snap layouts covering the work area without gaps, the safe calculator grammar, relative times and tolerant MPRIS metadata.
- ZIP with spaces, Unicode and shell metacharacters; one shared archive for a shelf selection; originals preserved; symlinks and remote files rejected.
- MCP lifecycle, tool schemas, JSON-RPC framing and rejection of unknown methods/arguments.
- Thunderstorm logic (`tests/launcher.test.js`): match weighting (exact > prefix > word start > substring > initials > fuzzy), ranking with frecency and per-category caps, the usage history, German number formatting, unit conversion in all categories and German/English queries, quicklink templates (URL encoding, `{path}`, rejected schemes and app ids), saved-list validation and snippet placeholders.
- The file search helper (`tests/test_filesearch.py`): Tracker's cursor format including unbound values, full-text terms reduced to plain prefixes (no FTS operators or SPARQL), the bounded fallback crawl, hidden files only on request, vanished files dropped and unreadable ones flagged, GTK's recently-used list, and the line protocol answering every request while superseding stale searches.
- The built-in AirPods reader (`tests/test_aap.py`): packets recorded from real AirPods Pro 2 — model, batteries with the primary bud, charging, ear state, noise control, conversation awareness — malformed packets ignored, commands encoded, and the helper's line protocol with a replayed channel.
- The shelf's context menu entries (`tests/test_tray_menu.py`): generic actions for any file, tool actions only with their program installed, AirDrop only with its backend, multiple selections applying actions to every matching file (with counts for partial matches), submenus for image formats and video sizes.
- Real GStreamer spectrum analysis of a synthetic tone and rejection of microphone sources.
- The cover helper against a local HTTP server: PNG normalisation, size limits, cache and rejection of invalid data.

`bash scripts/test-shell.sh` builds the package and starts **GNOME Shell 50** with a virtual monitor, a separate session bus and temporary XDG directories. Thunderstorm talks to a stand-in LocalSearch endpoint (`tests/mock_localsearch.py`, `NOTCHY_LOCALSEARCH_NAME`) and its fallback is confined to the test's own folder (`NOTCHY_FALLBACK_ROOTS`), so the real index and home folder are never touched; AirPods come from a stand-in airpods-helper daemon (`tests/mock_airpodsd.py`, `NOTCHY_AIRPODS_NAME`) or from recorded AAP packets (`NOTCHY_AAP_REPLAY`); `NOTCHY_NO_SYSTEM_BLUETOOTH` keeps the machine's real Bluetooth out of the test. The log must contain `NOTCHY_SHELL_TEST_OK`, `NOTCHY_PREFS_TEST_OK` and `NOTCHY_TRAY_TEST_OK`; `Gjs-CRITICAL`, `Script failed` or Python tracebacks fail the run. Every `PASS:` line is one concrete assertion. Among other things it checks:

- Top-bar integration: GNOME's clock in the middle of the capsule, both styles (Dynamic Glass flush with outward top corners that widen with the notch, Liquid Glass with a 3 px inset), no floating surface while closed, the clock restored on disable.
- Media through an MPRIS fixture: metadata, HTTP and local covers, raise, pause/seek, a real pointer click on play/pause, cover and waveform in the capsule, GStreamer levels; the output button and list with an AirPlay receiver (stubbed outputs — the test never touches the real network).
- Four tabs with one shared height, sliding indicator, clock in the header; keys 1–4 and Esc after an explicit open; spring morph with intermediate sizes, interrupted closing; 100 % black hides the glass.
- Calendar: native D-Bus events through a fixture, week strip with today selected and event dots, day selection, week arrows, calendar week, grouped notifications.
- Thunderstorm: focus, arithmetic result, copy with Enter, empty results.
- Radial menu: five actions centred below the clock, Esc; a real screenshot lands in the shelf, confirmed by a toast inside the capsule, collapsed and opened.
- Volume/brightness inline in the capsule instead of GNOME's OSD; scrolling over the capsule with a controlled mixer (one wheel step counts once); Caps Lock in the capsule, Num Lock silent.
- Glass layer exactly behind the island; the native shelf and drop zone shown as clones exactly over their windows on top of the whole glass, with nothing of Notchy among the windows; screenshots of both styles over a colourful backdrop. (Damage-clipped repaints, where the old in-between glass layer failed, do not occur in full-screen test screenshots; check moving windows behind the Regal on a real desktop.)
- Notification banners instead of GNOME's banners.
- Clipboard: recording, autofocus, arrow keys, F, ★ and link filters, copy with Enter, file and PNG contents.
- Basket as a native Wayland window at the pointer; corner rounding, multi-select and copy in the GTK helper (`tests/tray.py`).
- Real file drags from Wayland and X11 windows onto the island: drop zone right below the clock, COPY confirmation, multiple files, Esc cancel, ordinary hover afterwards.
- Snap layouts: a real window dragged by its title bar to the clock opens the layouts; the hovered zone lights up and GNOME's tile preview shows the target; releasing tiles the window onto the left half of the work area.
- Super+Space with real key events opens the search every time; GNOME's layout-switch keys are borrowed with one layout and restored on disable.
- Real right clicks open the radial menu; the outer corners follow the bar's slide-in at login.
- The shelf's real context menu (`regalMenuRegressions`): a real right click selects the tile and opens a GTK popover right at the pointer, inside the work area, shown as a clone on top of the island and every chrome layer while clicks over the island reach the popup; leaving the island keeps island and menu open (hover collapse is held); Esc, a click outside and a click on the tab bar close only the menu; arrow keys and Enter run an entry; a right click on another tile moves the selection; Ctrl+click builds a multiple selection whose menu acts on all files, and a real click on „Aus Regal entfernen“ removes both while the originals stay. Tiles deselect on a second click (`tests/tray.py`).
- Thunderstorm (`launcherRegressions`): files and folders from the stand-in index with name, kind and folder; hidden and vanished files left out; prefix matches above substring matches; late file results take the top unless the user moved; a burst of seven keystrokes asks the index once; a slow answer to an overtaken query is dropped; the action panel (Ctrl+K) copies the path, Ctrl+Enter shows the file in the file manager, Enter opens it after an existence check; arithmetic and units (copy on Enter); quicklinks with an encoded argument, keyword completion and `gh owner/repo`; lock through GNOME's ScreenSaver interface, shutdown and restart only after a second Enter (Esc cancels) through the session manager — all external calls recorded, never executed; recently used results on the empty field; emoji; snippets; the clipboard history only while recording; window commands on the previously focused window (left half, maximise); the indexed folder list; and the fallback search with its message once the index is gone.
- AirPods (`airpodsRegressions`): no state and no media row without the daemon; the daemon detected over D-Bus; connecting grows the island into the connection card with the name, unknown batteries as „–“, the pictures springing in, the ring filling while the number counts up, both buds in one ring within 10 % and one ring each beyond; a notification arriving with the card waits and shows once it folds away; without the daemon, the built-in AAP reader with recorded packets (batteries, model features, the card waiting for an open tab, ear pause, noise control sent over AAP, the reader ending on disconnect); the media tab lists batteries, the model's modes and conversation awareness, follows PropertiesChanged and sets modes in the daemon; unshown property chatter does not redraw; a bud out of the ear is dimmed; the media pause is the daemon's PauseOnRemoval; an ANC-only model hides adaptive and conversation awareness; the row fits between transport and output while music plays; low battery warns once; disconnecting is announced and leaves a „Verbinden“ row; connect and disconnect go through the daemon; Thunderstorm offers AirPods commands; turning the integration off and the daemon vanishing are handled; three disable/enable cycles leave no timers or signals.
- AirDrop through `tests/mock_airdropd`, a stand-in for `airdropd` with the same verbs, state JSON and `AIRDROP_CONFIRM` contract but no radio: arming, the capsule activity, consent in the notch (accept, Escape declines), received files in the shelf, sending with peer name and failure text, and a real drag onto the AirDrop zone. The test points `NOTCHY_AIRDROP_RUNDIR` at a private directory so a real backend's state is never touched.
- Native shelf between the clock row and the tab bar: geometry, glass below it in both styles, drag-out into another Wayland client, switching via the tab bar, process reuse, overview, context-menu hold and Esc.
- Preferences through GNOME's D-Bus service (one window for repeated clicks) and disable/enable without leftover timers or signals.

`NOTCHY_TEST_DROP_ONLY=1 bash scripts/test-shell.sh` runs only the interaction part (sentinel `NOTCHY_DROP_TEST_OK`), `NOTCHY_TEST_CORNERS_ONLY=1` only the GTK corner test, `NOTCHY_TEST_REGAL_ONLY=1` only the context menu, `NOTCHY_TEST_LAUNCHER_ONLY=1` only Thunderstorm and `NOTCHY_TEST_AIRPODS_ONLY=1` only AirPods. With `NOTCHY_TEST_SHELL_THEME=/path/gnome-shell.css` the bar geometry is additionally checked under a custom Shell theme.

## Normal desktop session

The headless test does not replace real use. After installing and logging in again, check:

1. Hover, click, shortcuts, pin, Esc; both styles with your own panel theme (transparent bar: corners of the Dynamic Glass notch).
2. Volume keys and scrolling over the capsule with real hardware; brightness.
3. Drag files from Nautilus onto the island, shake for the basket, drag out of shelf and basket, Zip/Convert.
4. Drag windows to the clock and place them with each layout.
5. Media: switch playback to an AirPlay receiver and back.
6. AirDrop (after installing airdrop-mt7921): receive a photo from an iPhone set to „Everyone“, send one back, and check the Wi-Fi reconnects afterwards.
7. Radial menu: area, window, screen, recording, text recognition (Tesseract).
8. Notifications from real apps, Do Not Disturb, calendar with a configured account.
9. Fullscreen, overview, scaling; disable/enable several times.
10. Shelf context menu: right click a file near each edge of the pane, with 100 % and fractional scaling (125 %, 150 %) and on a second monitor if the bar's monitor changes; the menu must open at the pointer, stay fully visible above the island and never be cut off; Esc and a click elsewhere close only the menu; submenus (with ImageMagick/FFmpeg installed); Menu key / Shift+F10.
11. Thunderstorm with the real LocalSearch index: a few known file names, a folder, a file on a USB drive before and after unplugging it, a file without read permission, a hidden file with a `.` query; Settings → Thunderstorm → add a folder to the index and find a file in it after LocalSearch indexed it; stop LocalSearch (`systemctl --user stop localsearch-3.service`) and check the fallback message; quicklinks, units, lock, settings panels, window commands, emoji, snippets.
12. AirPods without airpods-helper: connect them (card, batteries filling up), take a bud out (music pauses, resumes when it is back), switch noise control in the media tab. Then with airpods-helper installed: connect a pair (banner and batteries), switch ANC/transparency/adaptive, take a bud out (dimmed, media pauses through the daemon if enabled), let a bud run low, disconnect and reconnect from the media tab; without the daemon, the BlueZ fallback.
