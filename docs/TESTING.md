## GNOME releases

`bash scripts/test-matrix.sh [47 48 49 50 51]` runs `check.sh` and `test-shell.sh` once per supported GNOME release, each in a container that ships it (`tests/matrix/Dockerfile`, Ubuntu: 25.04 → 48, 25.10 → 49, 26.04 → 50, 26.10 → 51; `tests/matrix/Dockerfile.fedora`, Fedora 41 → 47.10, as Ubuntu only ever shipped 47.0) with a private session and system bus, software rendering and German language packs. Fedora's GNOME 47 also needs `org.freedesktop.locale1` on the system bus; the matrix starts a stand-in (`tests/matrix/localed.py`). `NOTCHY_MATRIX_SUITE=check` or `shell` runs one part; the `NOTCHY_TEST_*_ONLY` variables above are passed through. Logs, screenshots and each part's exit status land in `tests/output/matrix/gnome-N/`; a release counts as passed only when every part it ran reported success. The package built inside a container lists the release under test in its `shell-version`, so GNOME loads it before `metadata.json` declares the release. `.github/workflows/tests.yml` runs the same matrix in CI. Results per release and the API differences behind them: [`COMPATIBILITY.md`](COMPATIBILITY.md).

## Normal desktop session

The headless test does not replace real use. After installing and logging in again, check:

1. Hover, click, shortcuts, pin, Esc; both styles with your own panel theme (transparent bar: corners of the Dynamic Glass notch).
2. Volume keys and scrolling over the capsule with real hardware; brightness.
3. Drag files from Nautilus onto the island, shake for the basket, drag out of shelf and basket, Zip/Convert.
4. Drag windows to the clock and place them with each layout.
5. Media: switch playback to an AirPlay receiver and back.
6. AirDrop (after installing airdrop-mt7921): receive a photo from an iPhone set to „Everyone“, send one back, and check the Wi-Fi reconnects afterwards.
7. Radial menu: area, window, screen, recording, text recognition (Tesseract).
8. Notifications from real apps, Do Not Disturb, calendar with a configured account.
9. Fullscreen, overview, scaling; disable/enable several times.
10. Shelf context menu: right click a file near each edge of the pane, with 100 % and fractional scaling (125 %, 150 %) and on a second monitor if the bar's monitor changes; the menu must open at the pointer, stay fully visible above the island and never be cut off; Esc and a click elsewhere close only the menu; submenus (with ImageMagick/FFmpeg installed); Menu key / Shift+F10.
11. Thunderstorm with the real LocalSearch index: a few known file names, a folder, a file on a USB drive before and after unplugging it, a file without read permission, a hidden file with a `.` query; Settings → Thunderstorm → add a folder to the index and find a file in it after LocalSearch indexed it; stop LocalSearch (`systemctl --user stop localsearch-3.service`) and check the fallback message; quicklinks, units, lock, settings panels, window commands, emoji, snippets.
12. Compact notch with music: play music, note the closed width, hover open and leave several times, press Super twice, compare; switch tracks while it is open.
13. Agents: Settings → Agenten → „Einrichten“ for Claude Code (and Codex/Antigravity if installed; in Codex trust the hooks with `/hooks`). Start a session (idle indicator), send a prompt (turning ring), let it ask for a permission (orange, „?“), approve (working), let it finish (✓, then idle), click its indicator during a task (the card), click a ring to switch, let a task finish while you look elsewhere (stays green until you open the card or the window); two sessions in two terminals; quit one; kill one (`kill -9`) and wait ~10 s. With AirPods connected the notch must stay centred and nothing may overlap the clock or GNOME's panel items, also at 125 %/150 % scaling and on a narrow display. „Entfernen“ must leave your own hooks as they were.
14. Live activities: copy a large folder in Files with its window open (percentage, then a check), zip a large file from the Regal (its bar in the notch), start „timer 1 min“ in Thunderstorm and let it ring, a Pomodoro across a break, record the screen from the radial menu (red dot and time) and stop it with GNOME's own button; with music playing check the notch does not jump between them, that an agent waiting for you takes the notch at once and that the notch keeps its width and centre after opening and closing it; with 125 %/150 % scaling and on a narrow display.
15. Phones by QR code: drop a photo on „An Handy senden“, scan the code with an Android phone and an iPhone in the same Wi-Fi, download (the banner shows the phone and the progress, then folds away); several files as ZIP; with AirDrop installed switch the pill to the QR code (the code appears after the Wi-Fi is back); receive photos from the phone through the header's button (the question in the notch, the files in the Regal); a guest network with client isolation (it cannot work — the phone's page does not open).
16. AirPods without airpods-helper: connect them (card, batteries filling up, the symbol beside the notch and its controls), disconnect and reconnect several times (the batteries must return every time), take a bud out (music pauses, resumes when it is back), switch noise control in the media tab. Put both buds in your ears and check the case shows its last value greyed with its age (not live); put one bud back into the case and the case must turn live again. Then with airpods-helper installed: connect a pair (banner and batteries), switch ANC/transparency/adaptive, take a bud out (dimmed, media pauses through the daemon if enabled), let a bud run low, disconnect and reconnect from the media tab; without the daemon, the BlueZ fallback.
